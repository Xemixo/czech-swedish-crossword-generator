Generátor a řešitel švédských křížovek

Výkonný procedurální generátor a řešitel českých švédských křížovek. Využívá constraint satisfaction problem (CSP) s propagací omezení AC-3, podporuje vkládání tajenek na míru a exportuje samostatné interaktivní HTML pro luštění i tisk.

Přímo vygenerované křížovky hratelné v prohlížeči. Podporují navigaci šipkami, kontrolu chyb i odhalení tajenky.

Technické vlastnosti

Klíčové algoritmy a principy implementované v modulu crossword_core.

CSP řešitel (AC-3 + MRV)

Formulace jako problém splňování podmínek. AC-3 propagace průběžně ořezává domény slov a MRV (Minimum Remaining Values) heuristika vybírá nejvíce limitované sloty.

Česká abeceda a spřežka CH

Podpora všech českých znaků s diakritikou. Spřežka CH je reprezentována jako samostatná jednotka v interní abecedě a zabírá jedno pole v mřížce.

Vkládání tajenek

Zadání libovolného slova nebo fráze. Algoritmus prohledá dostupné letter buňky, nalezne souvislou či čitelnou sekvenci a zafixuje písmena do CSP řešitele.

Kategorizovaný slovník

Databáze 19 500+ hesel s ověřenými definicemi rozdělenými do úrovní Snadná, Střední a Těžká pro volitelnou obtížnost generování.

Procedurální generování sítě

Algoritmus automaticky umisťuje legendová pole a černé buňky pro libovolné rozměry od 4x4 do 30x30 s garancí platných délek slov (2 až 7 znaků).

Interaktivní HTML export

Generuje čistý, samostatný HTML soubor bez externích CDN závislostí. Obsahuje ovládání z klávesnice a CSS pravidla pro tisk na papír A4.

Použití z příkazové řádky

Příklady volání binárního nástroje cwgen.

# Interaktivní režim (dotaz na rozměr a tajenku):
cwgen

# Snadná křížovka 10x10 se zadanou tajenkou:
cwgen --size 10x10 -D easy -s "LES"

# Střední obtížnost 12x10:
cwgen --size 12x10 -D medium -s "PRAHA"

# Velká křížovka 20x20 s výstupem do vlastního HTML souboru:
cwgen --size 20x20 -D easy --html output/krizovka.html

# Zobrazení vyřešené mřížky přímo v terminálu:
cwgen --size 8x8 --ascii
