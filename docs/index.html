Generátor a řešitel švédských křížovek

Výkonný procedurální generátor a CSP řešitel české švédské křížovky. Podporuje automatické generování mřížek od 4×4 do 30×30, vkládání tajenek, export do interaktivního HTML pro tisk a hraní i CwdStudio XML.

Klíčové vlastnosti generátoru

Navrženo od základu pro maximální rychlost, správnou českou typografii a uživatelský komfort.

⚡

Výkonný CSP řešitel

Používá AC-3 algoritmus pro propagaci omezení a MRV (Minimum Remaining Values) heuristiku k bleskovému prohledávání stavového prostoru.

🔤

Pravá česká abeceda a CH

Plná podpora českých diakritických znaků a správné zacházení se spřežkou CH jako jediným písmenem v křížovkářské síti.

🎯

Vkládání tajenek na míru

Zadejte libovolné tajenkové slovo. Generátor najde optimální cestu mřížkou a předvyplní tajenková políčka do řešení.

📚

Ověřený slovník s obtížností

Více než 19 500 českých slov s přesnými nápovědami rozdělenými do kategorií Snadná (pro děti/začátečníky), Střední a Těžká.

📱

Interaktivní HTML export

Generuje samostatné, responzivní HTML křížovky hratelné na počítači i mobilu, se styly pro kvalitní tisk na papír (A4).

📐

CwdStudio XML kompatibilita

Výstupní soubory XML lze přímo načíst do specializovaného křížovkářského programu CwdStudio pro další sazbu či publikaci.

Rychlé spuštění a příkazová řádka

Aplikaci lze ovládat interaktivně pouhým dvojklikem nebo pomocí bohatého CLI.

# 1. Spuštění interaktivního průvodce bez parametrů: cwgen.exe # 2. Vygenerování snadné křížovky 10x10 s tajenkou "LES": cwgen.exe --size 10x10 -D easy -s "LES" # 3. Vygenerování velké křížovky 20x20 se střední obtížností: cwgen.exe --size 20x20 -D medium # 4. Explicitní výstup do HTML a CwdStudio XML: cwgen.exe -S 15x15 -s "HVĚZDA" --html krizovka.html -o krizovka.xml
